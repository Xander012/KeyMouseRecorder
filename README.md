# 键鼠录制回放工具 (KeyMouseRecorder)

Windows x64 桌面应用，用于**全局录制**鼠标与键盘操作并按原始节奏**精确回放**。**Windows 11 风格**中文界面，支持系统托盘，数据保存在 exe 自身目录（便携式，不写入 C 盘），可打包为单文件 `.exe`，在无 Python 环境的电脑上直接运行。

---

## 一、技术方案与选型理由

**开发语言：Python（`keyboard` + `mouse` + `tkinter`），打包：PyInstaller。**

在 Python 与 C# 之间，本项目选择 Python，理由如下：

1. **底层钩子能力对等**：`keyboard`/`mouse` 库底层就是 Windows 的 `SetWindowsHookEx`（`WH_KEYBOARD_LL` / `WH_MOUSE_LL` 低级钩子），与 C# 原生实现同一套系统 API，游戏/全屏应用下均能生效。
2. **热键拦截（suppress）现成且正确**：`keyboard.add_hotkey(..., suppress=True)` 内置了处理修饰键（Ctrl/Shift/Alt）的状态机，拦截组合键时不会让目标程序看到"悬空"的修饰键。C# 需手写这段状态机。
3. **零编译依赖、跨版本稳定**：`keyboard`/`mouse` 是纯 `ctypes` 封装，无 C 扩展，任意 Python 版本可装（本项目实测 Python 3.14.7）。
4. **开发/维护效率高**：逻辑清晰、易于修改扩展。

**代价与取舍**：PyInstaller 单文件 exe 体积约 12.5 MB，启动时先解压到临时目录（首次启动稍慢 1~2 秒）；少数杀软可能误报（PyInstaller 通病，加白名单即可）。若进入带反作弊的严格环境，或追求极致体积/启动速度，建议改用 **C# WinForms + 原生 `SetWindowsHookEx`**，本项目的录制/回放/文件逻辑可直接平移。

---

## 二、功能特性

- **录制**：全局监听鼠标（移动轨迹、左/右/中键、双击、滚轮）与键盘（字母/数字/F1-F12/方向键/回车/空格/Tab/Esc/Backspace/Delete/Insert/Home/End/PageUp/PageDown/修饰键组合/Windows 键/小键盘/常用符号），每条事件记录**毫秒级时间戳**。
- **移动降采样**：按「最小采样间隔(ms)」+「最小移动距离(px)」双重降采样，可一键关闭移动轨迹录制（只录点击/滚轮），避免脚本过大。
- **回放**：按原始时间间隔精确回放；支持**回放次数**（单次/指定次数/0=无限循环）与**速度倍率**（0.5x / 1x / 2x / 4x）。
- **紧急停止**：任何时刻按停止热键立即中止，并**自动释放所有按下的键**（含 Ctrl/Shift/Alt/Win）。
- **文件管理**：脚本保存为 `.macro`（内容为 JSON），支持保存/加载/重命名/删除，多脚本列表管理。
- **控制热键**：默认 `F6`=开始/停止录制、`F7`=开始/停止回放、`F8`=紧急停止、`Ctrl+F12`=显示/隐藏主界面，全部**可自定义**（「检测按键」输入框，按下即捕获）。
- **系统托盘**：关闭窗口即最小化到托盘，右键托盘图标弹出菜单。
- **Windows 11 风格界面**：Fluent 浅色主题（`#0067C0` 强调色、微软雅黑 UI 字体、扁平按钮、白色输入框、高分屏 DPI 感知）。
- **便携式存储**：配置、脚本、日志均保存在 exe 自身目录（`config.json` / `macros\` / `app.log`），不写入 C 盘，整个文件夹拷走即用。
- **窗口置顶**：可一键让窗口固定在最上层（默认开启），便于在游戏/全屏应用中随时观察状态与控制。
- **迷你悬浮条**：可拖动、置顶的迷你状态条（状态点 + 「● 录制 / ■ 停止」按钮 + ✕），便于在游戏（无边框窗口模式）中浮层快速控制；主界面顶栏「悬浮条」复选框开关。
- **声音提示**：开始/停止录制、开始回放、回放结束/中止均有不同提示音，便于在看不到窗口的全屏场景判断状态；可在「设置 → 提示」中关闭。

## 三、快速开始

### 直接运行 exe
双击 `dist\KeyMouseRecorder.exe` 即可（无需安装 Python）。首次运行会在 **exe 自身目录**下创建 `config.json`、`app.log` 与 `macros\` 脚本目录（便携模式，不写入 C 盘）。

### 从源码运行
```bat
pip install -r requirements.txt
python main.py
```

## 四、使用方法

### 1. 录制
1. 点击「**开始录制**」按钮，或按热键 `F6`。
2. 在目标窗口/游戏中进行你要录制的操作。
3. 点击「**停止**」或再按 `F6` 结束。状态栏与日志会显示"已录制 N 个事件"。
4. 点击「**保存**」输入脚本名存为 `.macro`；或直接点「**回放**」。

> 录制期间控制热键本身照常生效，且**不会被录入脚本**（已在监听层拦截并丢弃）；界面状态栏会显示当前控制热键，防止误录。

### 2. 回放
1. 录制完成后，或先在脚本列表双击/「加载」一个脚本。
2. 设置「回放次数」（0=无限循环）与「速度」。
3. 点击「**回放**」或按 `F7`。
4. 回放中可随时按 `F8`（紧急停止）或再按 `F7` 立即中止，所有按键自动释放。

### 3. 自定义控制热键
1. 点击「**设置**」。
2. 在对应热键行点「**检测**」，然后按下你想要的组合键（如 `Ctrl+F9`、`F10`），自动捕获并回填。
3. 点「**保存**」。若新热键与其他控制热键冲突、或与当前脚本已录按键重叠，会弹出明显提示。

### 4. 文件管理
- 「保存」：保存当前录制内容。
- 「加载」：加载脚本列表中选中的脚本（双击也可）。
- 「重命名 / 删除」：管理脚本列表。
- 「打开目录」：打开 exe 自身目录下的 `macros\`。

### 5. 迷你悬浮条与声音提示
- **迷你悬浮条**：主界面顶栏勾选「悬浮条」即显示一个置顶小窗（状态点 + 「● 录制 / ■ 停止」按钮 + ✕）。按住空白处可拖动到任意位置，点按钮即开始/停止录制，状态点与主界面实时同步。游戏设为「无边框窗口模式」时可直接浮在游戏上方操作。
- **声音提示**：开始录制（一声）、停止录制（两声短音）、开始回放（一声高音）、回放正常结束（上行两音）、回放被中止（一声低音）。可在「设置 → 提示 → 声音提示」中关闭。在看不到窗口的独占全屏场景下尤其有用。

## 五、控制热键拦截实现说明（hook + suppress 取舍）

需求要求"控制热键按下时被消费，不入脚本、不上报目标程序"。实现方式如下，并说明取舍：

- **拦截控制热键**：用 `keyboard.add_hotkey(组合键, 回调, suppress=True)` 注册全部控制热键。
  - `suppress=True` 走库内 `blocking_hotkeys` 状态机，在钩子回调里返回 `False` 把整组键（含 Ctrl/Shift/Alt 修饰键）从系统消息流中"吃掉"，目标程序完全收不到。
  - **取舍**：`keyboard.hook(cb, suppress=True)` 是"全有或全无"——回调返回 `False` 拦、`True` 放，适合单键/重映射；但对"多键组合 + 修饰键"的精确拦截，需要自己写修饰键状态机（否则目标程序会看到悬空的 Ctrl）。`add_hotkey(suppress=True)` 已内置这套状态机并正确处理修饰键，因此**选它而非手写 `hook(suppress=True)`**。代价是灵活度略低（不能只放行组合中的某个键），对本应用场景无影响。
- **录制时过滤**：录制用**非拦截**的 `keyboard.hook(cb)`（只监听不拦截，保证用户正常操作能送达目标程序）。该 hook 会收到所有事件（含被 suppress 的），故在录制器内按"控制热键扫描码"过滤：热键触发时清除已录的该组合事件，并跳过其后续释放事件。
- **回放时防回捕**：回放注入按键时，`keyboard` 库置位 `is_replaying`，钩子对注入事件直接放行且**不触发任何热键**——因此脚本里即使残留控制热键，回放也不会再次触发录制/停止造成死循环；同时用户**物理**按下 `F8` 依然能立即停止。

## 六、打包为单文件 exe

已用 PyInstaller 6.x 打包，命令如下（在项目根目录执行）：

```bat
python -m PyInstaller --noconfirm --clean --onefile --windowed ^
  --name KeyMouseRecorder ^
  --icon assets\app.ico ^
  --add-data "assets\app.ico;assets" ^
  main.py
```

产物：`dist\KeyMouseRecorder.exe`（单文件，Windows x64，无控制台窗口）。若要改 exe 文件名，改 `--name` 即可；托盘图标来自打包时内嵌的 `assets\app.ico`。

> 重新生成图标：`python tools\make_icon.py`。

## 八、脚本文件格式（.macro = JSON）

```json
{
  "version": 1,
  "name": "录制_20260115_143000",
  "created_at": "2026-01-15T14:30:00",
  "duration_ms": 4321,
  "settings": {"record_mouse_moves": true, "sample_interval_ms": 15, "min_move_distance": 3},
  "events": [
    {"type": "key",   "action": "down", "code": 29, "name": "ctrl", "ts": 100.12},
    {"type": "key",   "action": "up",   "code": 29, "name": "ctrl", "ts": 100.65},
    {"type": "move",  "x": 320, "y": 240, "ts": 100.20},
    {"type": "mouse", "action": "down", "btn": "left", "ts": 100.80},
    {"type": "mouse", "action": "up",   "btn": "left", "ts": 100.95},
    {"type": "wheel", "delta": 1, "ts": 101.30}
  ]
}
```
- `ts`：`time.time()` 秒级浮点（毫秒精度），回放时换算相对间隔。
- `code`：键盘扫描码（物理键位，与输入法/布局无关，回放最忠实）。
- 可直接用文本编辑器查看/微调 JSON。

## 九、异常与健壮性

- 回放中目标窗口不存在/事件失败：捕获异常、写日志、状态栏提示，**不崩溃**。
- 回放结束或中止：自动释放所有已按下按键（`Ctrl/Shift/Alt/Win` 及鼠标按键兜底释放）。
- 日志写入 exe 自身目录下的 `app.log`，界面底部滚动显示。

## 十、常见问题

- **控制热键在目标软件里没反应了？** 正常——控制热键已被拦截（suppress），不会送达目标程序；这正是防死循环的设计。改用目标软件用不到的组合键即可（设置里改）。
- **全屏游戏里能用吗？** 能。录制/回放/控制热键用的是系统级低级钩子（`WH_KEYBOARD_LL`/`WH_MOUSE_LL`），独占全屏下也能生效。但三点注意：
  1. **管理员权限**：若游戏以「管理员身份」运行，本工具也必须以管理员身份运行，否则 Windows UIPI 会阻断钩子（钩子失效最常见的原因）。
  2. **反作弊**：带 EAC / BattlEye / Vanguard 的游戏可能屏蔽或检测低级钩子与注入，这是所有同类工具的通病，无法保证。
  3. **置顶窗口/悬浮条**：真正的「独占全屏」会独占整个屏幕，任何窗口（含置顶窗口与迷你悬浮条）都无法浮在其上；此时请改用控制热键 `F6/F7/F8`，并依靠**声音提示**判断录制/回放状态。若想看到悬浮条，把游戏设为「无边框窗口模式」即可。
- **杀软误报？** PyInstaller 单文件 exe 常见，加入白名单或改用 `--onedir` 打包。
- **回放位置不准？** 移动轨迹按屏幕绝对坐标回放，请保持录制与回放时屏幕分辨率一致。
